# 抖音带货首版边界

“抖音带货”是独立于发布中心的单任务工作流，只服务抖音本地团购视频：

1. 选择一个状态正常的抖音账号。
2. 选择一个本地视频并填写标题、文案与可选话题。
3. 视频上传完成后，客户端先显示该抖音账号已手动同步的本地收藏音乐缓存。用户点击“刷新”才会读取当前编辑页的“添加音乐 → 收藏”列表；用户必须自己选择一首并由编辑页回读，绝不默认选第一首。
4. 按抖音新版编辑器的实际流程，在“添加标签”中选择“位置”，再选择“带货模式”。地点范围默认显示“国内”，用户可以明确切换为“本地”；随后再输入地点关键词。实际范围必须由编辑页回读确认。
5. 从当前编辑页返回的候选中选择一项。候选必须同时可见名称和完整地址，并由页面回读确认发布位置；不读取、选择或绑定团购门店。
6. 在当前编辑页选择一项“作品内容声明（自主声明）”，并回读确认；不会从素材、标题或 AI 标记自动推断。
7. 选择发布方式：默认立即发表；如勾选定时，设置未来的 Asia/Shanghai 时间。若同一临时编辑页已写入过定时而要改回立即发表，必须重新上传，避免平台遗留定时状态。
8. 先执行预检；预检完成页面字段回读后，用户再次确认才允许最终提交。

## 客户端操作体验

- 页面采用“当前步骤主区 + 持续可见任务摘要”的桌面布局。摘要只显示已选择或已
  回读的最小事实，不把本地待填字段伪装成平台已生效。
- 顶部四步导航只允许回到当前或已完成步骤；未来步骤在对应的页面回读完成前不可
  跳过。用户可以修正前一步内容：只改标题、文案或话题时同步同一编辑页；只有改动
  账号或视频时才重新上传，避免复用不一致的编辑会话。
- 每个步骤同一时刻只突出一个可执行的主操作：上传视频、读取或确认音乐、搜索或
  确认定位、写入声明、进入检查、执行预检或最终确认。完成后的音乐与定位候选列表
  会折叠，保留可读的确认卡，避免大块空白和重复滚动。
- 定时不是必选项。默认保持立即发表；只有用户勾选定时后才显示并校验北京时间。
  预检通过仍只代表页面字段回读，最终提交前必须再次确认。

### 收藏音乐缓存

- 缓存仅保存在本机，并严格按一键发中的抖音账号隔离；只保存平台稳定音乐 ID、
  标题、作者、时长和本机同步时间，不保存 Cookie、二维码、DOM 标记、页面 HTML 或
  请求数据。
- 平台页面只会在用户点击“刷新”后读取。没有缓存时，客户端提示刷新，不会自动打开
  音乐抽屉、登录、上传、保存草稿、预览或发表。
- 从缓存选择音乐不表示平台已设置：一键发仍会在当前无头编辑页重新打开收藏列表，
  以同一音乐 ID 唯一匹配、点击并回读。缓存过期、ID 重复、控件变化或回读不一致都会
  安全停止并要求刷新，绝不会退回选择第一首或按标题模糊匹配。
- 缓存不构成平台草稿、定时或发布证据；只有后续对应的页面回读和平台回执才改变任务状态。

## 任务字段

每个抖音带货任务在既有任务载荷中标记：

- `workflow=douyin-commerce`
- `commerceMode=local-group-buy`
- `locationPoi`：本次带货位置的可回读标识、名称、完整地址和距离。新版页面未公开普通 POI ID 时，标识由可见名称和完整地址生成，不读取私有请求或隐藏数据。
- `locationScope`：用户明确选择的地点搜索范围，仅为 `local`（本地）或 `domestic`（国内）
- `contentDeclaration`：用户从抖音当前页面明确选择并回读的作品内容声明
- `musicMode=favorite-manual`：用户从当前编辑会话的抖音“收藏”列表选择音乐
- `selectedMusic`：本次用户所选音乐的最小回读字段（平台可读身份、名称、作者、时长）；不保存瞬态 DOM 标记
- `enableTimer`：`true` 为定时发表，`false` 为立即发表
- `scheduleTime`：仅 `enableTimer=true` 时存在，格式为 `YYYY-MM-DD HH:mm`，按北京时间解释

任务不保存 Cookie、二维码、原始页面请求、账号凭据或门店库；历史载荷中的 `commerceStore` 会在新任务校验时被丢弃。

## 执行与安全停止

受控浏览器的固定顺序是：账号回读 → 上传视频 → 填写内容 → 跳过独立封面设置 → 读取收藏音乐 → 用户选择并回读音乐 → 添加标签中的“位置” → 带货模式 → 用户明确选择本地/国内范围 → 输入地点 → 选择并回读位置 → 选择并回读作品内容声明 → （如启用）设置并回读定时 → 最终提交 → 管理页回读。

上传后的编辑会话只保留在一键发本机内存。改变账号、视频、标题、文案或话题时，旧会话会被放弃并要求重新上传；不会保存草稿，也不把二维码、Cookie、页面 DOM 或音乐行标记写入任务。

- 预检可以上传测试视频并填写字段，但绝不点击最终发表。
- 抖音带货不进入封面裁剪流程，避免封面浮层遮挡地点或带货控件；普通抖音视频发布不受此规则影响。
- 二维码、验证码、登录失效、未知合规或风控提示、控件变化、收藏为空、音乐选择或回读不唯一、地点范围/候选不唯一、位置或声明回读不一致都会停止，不记为已定时。
- 定时任务只有实际管理页回读到指定标题和定时时间，且编辑页回读到指定位置和作品内容声明，才会标记为已定时；立即发表任务必须收到平台发布回执，不能由预检或页面填写推断成功。
- 首版不支持图文、文字、多账号、门店绑定、商品或套餐选择、商品库管理，也不使用官方 API、签名参数或私有接口。
