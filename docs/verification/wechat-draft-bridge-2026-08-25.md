日期：2026-08-25（Asia/Shanghai）

## 本轮范围

- 输入只允许硅基进化 V1.2 `release_ready` 冻结包，且必须明确 `publish_allowed=false`。
- 一键发只允许保存公众号草稿，并在草稿列表按账号、标题、封面和保存时间窗口回读唯一结果。
- 禁止发表、群发、定时发表；内容项目的原文章状态不因草稿回执改变。

## 已实现的离线边界

- 冻结包会重新校验整包哈希与清单中每个文件的哈希，路径越界、素材变化或发表授权开启都会停止。
- 冻结 HTML 保持原样式和正文顺序，只移除本地图片占位并按正文锚点上传对应图片；摘要也必须写入后精确回读。
- `wechat_draft` 是独立运行模式，只接受单个公众号账号，并强制关闭群发和定时配置。
- 保存草稿后重新确认当前账号，再进入草稿列表；只有本次时间窗口内同标题、带封面的唯一结果才算成功。
- 本地收件箱、并发锁和回执使用原子文件；同一文章和同一冻结包已经有终态回执时不会重复执行。
- 桌面开关默认关闭，首次开启前明确说明只保存草稿；关闭后不轮询收件箱。
- 内容项目只登记文章 ID 与冻结包哈希完全匹配的回执，不改变本地交付或人工发表状态。
