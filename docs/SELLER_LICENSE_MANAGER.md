# 一键发卖家激活码管理器

## 当前范围

当前采用本地离线签发：客户首次启动有 7 天试用；购买后把客户端显示的 32 位机器码发给卖家，卖家在独立的“一键发激活码管理器”中生成设备绑定激活码。

本工具不是在线授权平台，不提供联网订单、撤销、换机或套餐管理。激活码生成、历史记录和私钥均只留在卖家电脑。

## 日常出码

1. 打开 `~/Applications/一键发激活码管理器.app`。
2. 粘贴客户的一键发机器码，填写订单备注。
3. 选择长期有效或指定到期日期。
4. 点击“生成并复制激活码”，再发给客户。
5. 客户在一键发激活窗口粘贴并激活。

管理器保存最近 500 条记录，便于售后重新复制。新版本继续兼容原“发射台”私钥目录，因此既有私钥和已签发激活码不会因品牌迁移而失效。

## 构建与安装

在项目根目录执行：

```bash
.venv/bin/python seller_tools/build_macos_app.py
```

构建器会先生成独立 macOS 应用，确认产物不含私钥和出码记录，执行离屏 UI 自检，然后安装到 `~/Applications/一键发激活码管理器.app`。

## 安全边界

- 私钥和 `issue-history.json` 不提交 Git，也不进入一键发客户包。
- 客户 Mac、Windows 构建在归档阶段会拒绝 `seller_tools/`、`license-private.json` 和 `issue-history.json`。
- 不向客户发送卖家管理器。
- 不在聊天、日志、截图或测试输出中展示私钥内容。
