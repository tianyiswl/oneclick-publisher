本次复审修复还补齐了四项可审计边界：

- 小红书浏览器成功同步现在额外返回受控清理回执，只有 `closed=true` 且内建整数
  `aliveResourceCount=0` 才能随成功结果出现；关闭失败保持失败，并返回非零计数，不附带异常原文。
- `validation_mode=true` 必须由调用方显式提供受控的 `visible_readback`，才会使用 headed 官方只读浏览器；
  普通同步仍保持原有 headless 语义且不读取页面可见摘要。验证模式只接受白名单的粉丝累计、单条作品 ID
  和播放累计值；同步写入后立即用同一账号的本地查询逐项比对，并把比对结果仅返回给本次调用，
  不写进数据库、日志或文件。
