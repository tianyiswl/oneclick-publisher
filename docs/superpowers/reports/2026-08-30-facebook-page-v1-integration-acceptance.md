## 通过的合同

- 精确绑定并回读 Facebook Page 身份；仅接受单 Page、单视频、立即公开的 V1 输入合同。
- 特性开关默认关闭；关闭时登录、检测、刷新、授权、预检、正式执行和公开对账均在核心服务入口拒绝，不启动浏览器或改变任务。
- UI、CLI、内容项目 Gateway 与 MCP 共用同一发布服务；正式动作需要一次性短期授权和 Page 级原子 claim。
- 视频绝对路径只在运行时短暂使用；数据库和公开投影只保留文件名、大小和哈希，并在运行前重新校验。
- 最终点击前重新回读 Page、视频、文案、公开范围与按钮；漂移时保持零点击并安全终止。
- 人工安全验证作为 claim 之上的等待层；CLI、Gateway、MCP 和桌面持续返回验证类型与有效截止时间，验证前后不重传或重开任务。
- worker token、心跳、失联恢复、Ctrl-C、只读对账和最终回执均使用条件写入；终态不会被迟到回调重开，点击后不明结果不会自动重试。
- 删除或重绑账号时，共享会话文件、头像、路径别名、异常路径和并发引用采用保守清理；YouTube 不透明凭据引用保持独立语义。
- 旧 Meta type 8、YouTube、TikTok 与国内功能离线回归保持通过。
