- 根因：`广东joymark`、`江苏joymark` 等地区前缀会把平台首屏候选过滤成目标地区子集；旧代码把这个子集当作平台完整快照传给“加载更多”，与采集器保存的真实首屏身份不一致，分页被安全检查拒绝。
