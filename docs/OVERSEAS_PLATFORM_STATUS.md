# 海外平台接入状态

| 平台 | 浏览器账号与预检 | 官方授权/API | 正式动作 | 当前边界 |
| --- | --- | --- | --- | --- |
| TikTok | 已接入可见登录、静默检测与 Post 前预检 | 已接入 OAuth 与收件箱上传 | 仅上传到用户收件箱 | 不等同于公开发布；Direct Post 保持锁定 |
| YouTube | 已接入可见登录、静默检测与 Done 前预检 | 已接入 OAuth、视频/封面上传、可见性、定时与结果回读 | 官方 API，执行前二次确认 | 需要项目自有 Google OAuth 配置及真实频道验收 |

| Facebook Reels | 与 Instagram 共用 Meta 浏览器会话，可预检 | 已接入 Meta OAuth/Graph API 容器与结果回读 | 官方 API，或二次确认后的可见浏览器通道 | 需要 Meta 应用权限、主页绑定并做真实验收 |

Instagram 与 Facebook 的浏览器方式使用同一份 Meta Business Suite 会话；官方 API 则按实际授权到的主页、专业账号建立独立发布目标。浏览器账号和官方 API 账号不能在同一平台任务中混用。

## 一键发内的授权方式

- “绑定账号”用于一键发自己的本地浏览器会话，登录窗口只在用户主动绑定或重新登录时打开。
- “官方 API 授权”用于导入本项目的开发者配置并发起 OAuth。令牌仅保存到本机私有数据目录，不写入数据库、Git、发布包或日志。
- 账号列表只保存平台、显示名、非敏感平台账号标识和授权通道；不会把 access token、refresh token 或 Cookie 当作账号字段保存。
- 普通“检测登录”保持静默；出现会话失效或平台要求用户操作时只报告状态，不自动登录。

## 正式任务门槛

1. 只支持视频内容；海外图文与纯文字不会创建伪任务。
2. 官方 API 正式上传必须精确选择一个官方授权账号，并在通用发布确认后再次勾选确认。
3. Meta 浏览器正式通道必须保持浏览器可见，并完成两项一次性确认；验证码、双重验证、安全检查或未知弹窗会安全停止。
4. TikTok 官方通道当前只允许独立的收件箱上传任务，成功含义是“已进入收件箱、尚未公开发布”。
5. 任何通道只有回读到可区分的平台成功或定时证据，才会将对应执行项记为成功；按钮点击、请求发出和页面跳转都不算成功。

## 尚未完成的真实验收

当前版本完成的是源码接入、界面门控和离线回归；未在本轮使用真实海外开发者配置、账号或素材执行平台上传。下一步需要 Andy 在一键发内按平台完成开发者配置和官方授权，再以专用测试视频逐个平台验收账号回读、字段、定时与最终平台回执。

## 安全边界

- 二维码、Cookie、storage state、OAuth 令牌和账号凭据不写入代码仓库、安装包、发布包或长期日志。
- 异常登录、验证码、二次验证、风控、未知合规弹窗或无法区分的回执都是安全停止条件。
- 若平台返回远端任务标识后发生异常，一键发会提示先到平台核对，不会自动盲目重试，避免重复发布。
