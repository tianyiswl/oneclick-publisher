# 平台数据会话采集

## 当前范围

数据监测首期支持已在“账号管理”中登录的抖音账号，可读取播放、点赞、评论、分享、粉丝、净增粉和主页访问。缺失数据显示为“—”，不伪造为 0。

## 读取路线

1. 先使用账号已保存的 Cookie 和登录会话，向固定的抖音创作者数据接口发起只读请求。
2. 若平台要求当前页面签名，则启动一个短生命周期的无头 Chromium，只接收官方页面自身返回的允许列表 JSON。
3. 每次同步只保存归一化后的指标和受控的成功/失败状态，不保存 Cookie、响应原文、HTML、DOM 或个人信息。

不进行 DOM 爬取，不使用自建签名服务，不绕过登录、验证码或平台权限。

## 故障语义

- `login_required`：已保存会话失效，需要返回账号管理重新登录。
- `verification_required`：平台要求用户完成验证。
- `metric_payload_empty`：平台未返回可用指标。
- `metric_payload_invalid`：指标响应无法通过语义验证。
- `sync_persist_failed`：本地指标快照写入失败。

失败同步不会清空上一次成功指标。页面继续展示历史成功快照，同时单独显示最新失败状态。

## 运行与退出边界

- 同一账号同时只能有一个数据同步任务。
- 界面进度仅展示固定阶段文案，不转发网络或异常原文。
- 关闭客户端时先取消未启动任务，并最多等待 5 秒收束已运行任务。若未收束，客户端拒绝继续关闭，避免留下活动浏览器资源。

## 验收边界

单元测试和离屏 UI 测试只证明本地代码契约。只有用真实已登录账号执行一次同步，并在“数据监测”页回读到新的成功快照，才达到真实运行验收。
